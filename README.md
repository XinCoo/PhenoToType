# SeedPhenotype Studio

**植物籽粒表型测定 + 一键生成科研级论文配图** 的本地桌面软件。

导入带标尺的籽粒散落俯视图，自动完成去背景、逐粒分割、轮廓提取、尺寸形态与颜色指标测定、组间统计，并一键输出符合 SCI 投稿规范的矢量图（SVG）/ 600 dpi 位图（PNG）。

- 纯本地运行，**零第三方运行时依赖**（所有图像处理与统计算法均为本项目手写 JS）
- 输出 **SVG 矢量图**，期刊缩放不失真；同时支持 600 dpi PNG
- 目标场景：谷子、小麦、水稻、玉米等作物籽粒的**批量表型测定**

## 使用流程

### 1. 导入图像

顶栏「导入图像」，或直接把图片拖到「图像与轮廓」页。

要求：
- **俯视散落照**，籽粒之间尽量不重叠（轻度接触可自动分离）
- **背景单一**（浅色台面或纯色背景最佳）
- **画面内有标尺或标定物**（毫米刻度尺、已知尺寸标定块均可）

一次可多选多张，每张图为一个「批次」。

### 2. 尺度标定

三种模式，在左栏「尺度标定」中选择：

| 模式 | 适用场景 | 操作 |
| --- | --- | --- |
| **不标定** | 只需要像素单位或相对大小 | 选「不标定」，输出 px 指标 |
| **自动识别标尺** | 图中黑色标尺条清晰、孤立 | 选「自动检测」，点「检测标尺」后点击画面中的标尺条 |
| **手动输入** | 有标定物但软件识别不出 | 选「手动标定」，填入「标尺像素长度 / 实际毫米数」 |

标定值是**全局设置**，修改后所有批次会统一重新分析，保证跨图可比。

### 3. 分割参数调节

| 参数 | 含义 | 调节建议 |
| --- | --- | --- |
| 最小面积 | 小于该像素数的连通域视为噪点丢弃 | 背景噪点多时调大；籽粒细小时调小 |
| 去噪（腐蚀/膨胀） | 平滑掩膜、填小孔 | 有毛刺时开1；籽粒相互粘连时关0 |
| 阈值偏移 | 微调 Otsu 自动阈值（负=更宽松） | 漏检偏严时调负；背景被误判为籽粒时调正 |

参数改动会触发**全批次重跑**，左侧状态栏显示每张图的耗时与检出粒数。

### 4. 查看与导出数据

「数据表」页列出全部样本的指标，可按分组/图像名搜索。顶栏可导出：
- **CSV**（含 UTF-8 BOM，Excel 直接打开不乱码；列名为中文）
- **项目文件**（`.json`，保存设置+全部测量结果，可再次载入复现分析；不含原始像素）

### 5. 统计分析

「统计分析」页选择任一指标，自动给出：
- 各组描述统计（n、均值、SD、CV、中位数、四分位、极差、95% CI）
- 单因素 ANOVA（F、df、p）
- 组间两两事后比较（**Tukey HSD / Games-Howell / Welch t / 自动**，设置面板可切换），均配 **紧凑字母标注**（compact letter display）
- Pearson 相关与线性回归（散点图页）

字母标注规则遵循惯例：不显著组共享字母，显著组绝不共享字母。
事后检验方法在「设置 → 事后检验」切换：`tukey`（方差齐，按族系错误率校正）、`games-howell`（方差不齐）、`welch`（不校正，兼容旧行为）、`auto`（先做 Bartlett 方差齐性检验再择一）。

### 6. 生成论文配图

「图表输出」页，8 种图型：

| 图型 | 用途 |
| --- | --- |
| 柱状图 `bar` | 均值 ± SE/SD，附字母标注 |
| 箱线图 `box` | 分布 + 离群点判定（1.5×IQR） |
| 小提琴图 `violin` | 分布密度 |
| 散点回归 `scatter` | 相关性 + 拟合线 + R² |
| 直方图+核密度 `hist` | 单组分布形态 |
| 相关热图 `corr` | 多指标相关性矩阵 |
| 多面板拼图 `composite` | 一次出多张子图组合 |
| 轮廓叠图 `contours` | 全部籽粒轮廓叠加（形状展示） |

绘图设置（左栏）：
- **配色方案**：Nature / Lancet / Science / Wiley / Okabe-Ito / 灰度（色盲友好）
- **图幅**：85 mm 单栏 / 180 mm 双栏 / 自定义
- **字号**：6–9 pt（期刊要求），联动 SVG 与 PNG
- **DPI**：PNG 光栅化分辨率，默认 600

页面底部「投稿规范检查」实时校验：字号是否越界、图幅是否超限、SVG 是否含 `NaN`/`undefined`、分组数与样本量是否满足统计要求。

顶栏可导出：
- **SVG**（矢量，优先投期刊）
- **PNG**（按 mm × DPI 计算像素尺寸）

## 测量指标

### 尺寸形态

| 指标 | 定义 |
| --- | --- |
| 长度 / 宽度 | 最小面积外接矩形（旋转卡壳）的长、短轴 |
| 长宽比 AR | 长 / 宽 |
| Feret 直径 | 轮廓上两点最大距离 |
| 等效直径 | √(4A/π) |
| 面积 | 鞋带公式多边形面积 |
| 厚度 | 轮廓面积 / 宽度（近似均值厚度） |
| 椭球体积 | 长、短、中轴估算的旋转椭球体积 |
| 圆度 circularity | 4πA / P²，1 为圆 |
| 凸实度 solidity | A / A(凸包) |
| 圆度比 roundness | 4(√(πA) / P)² |
| 长轴角度 | 长轴与水平方向夹角（rad） |

长轴拟合使用**二阶中心矩等效椭圆**，对真实椭圆精确、对任意形状稳健。

### 颜色（CIELAB）

`L*`（明度）、`a*`/`b*`（绿-红/蓝-黄轴）、彩度 `C* = √(a*²+b*²)`、圆周均值色相 `H*`、饱和度、`L*` 极差。

## 算法流程

```
PNG/JPG 解码
  → sRGB→Lab 转换，逐像素算与背景色的ΔE76
  → ΔE 直方图 Otsu 自动阈值（含背景峰，保证阈值落在双峰之间）
  → 形态学：腐蚀/膨胀去噪 + 填孔
  → 8 邻域连通域标记
  → 距离变换（两遍扫描 + chamfer 3×3 近似）
  → 粘连分离：局部极大值 → 核心标记 → 最大堆优先分水岭式传播
  → 逐粒独立掩膜 → Moore 邻域轮廓追踪（Jacob 停止准则）
  → Douglas-Peucker 简化（容差 0.2 px）
  → 几何描述子 + LAB 颜色统计
  → 尺度换算（mm/px）
```

**关于粘连分离**：算法只在「距离变换局部极大值足够大、能容纳两个半径≥ 该值一半的圆」时才拆分，因此单颗籽粒不会被误拆；核心标记过小时会并入主核心，避免把一颗籽粒切成几块。

### 精度验证

`test/fixtures/` 中提供合成 PNG 与 `truth.json` 真值。端到端测试确认：长轴/短轴/投影面积均值与真值误差 **< 0.15 mm**，等效直径满足 `d = √(4A/π)`。

## 拍摄建议（影响测量精度）

1. **相机垂直于台面**，避免透视变形；若无法垂直，务必在样品旁放标尺并与籽粒同平面
2. **背景与籽粒色差要大**（浅色籽粒配深色背景反之亦然）
3. **标定尺与籽粒同平面**，且不要被裁切
4. 避免强烈反光（可用漫射光/柔光箱）
5. 一次拍摄粒数不宜过多，重叠会降低粘连分离的可靠性

## 已知限制

- 仅支持俯视散落照，不支持堆叠/侧面视图
- 粘连分离对「严重重叠」（接触面超过短轴 1/2）会失效，此时应重新拍摄
- 自动标尺检测要求标尺条颜色与背景反差大且四周无干扰；识别失败请用手动标定
- 仅提供 Windows x64 打包；未做代码签名，首次运行 Windows SmartScreen 会提示"未知发布者"，选择"更多信息 → 仍要运行"即可
- 输出目录带版本号与时间戳（如 `release/v0.1.0-v1/`），多次打包结果并存，不自动清理旧产物

## 打包（Windows exe）

```bash
npm run dist        # 打包 exe + zip 便携包
npm run dist:dir    # 只出 exe 目录（不压缩）
npm run icon        # 重新生成 build/icon.ico
```

产物结构：

```
release/v<版本>-<标记>/
├─ SeedPhenotype Studio-win32-x64/
│  └─ SeedPhenotype Studio.exe        ← 双击即可运行（免安装）
└─ SeedPhenotype Studio-<版本>-portable.zip   ← 便携包，可拷贝到其他电脑
```

exe 为**绿色免安装版**：整个 `SeedPhenotype Studio-win32-x64` 目录一起拷贝即可，目标电脑无需装 Node 或 Electron。

**为什么不用 electron-builder**：其 `winCodeSign` 依赖解压含 macOS 符号链接的归档，Windows 普通权限下会失败（需管理员或开发者模式）。本项目改用 `@electron/packager`（纯 JS），并用 `rcedit` 写入图标与版本信息，构建链无权限依赖。

打包脚本 `scripts/build-win.cjs` 的做法：把 `src/`、`electron/main.cjs`、`electron/preload.cjs` 按白名单拷入暂存目录，清空 `devDependencies` 后再打包，确保 asar 里只有运行必需内容（实测 asar 约 0.1 MB，打包后目录 269 MB 主要是 Electron 运行时本身）。

> **注意**：从 IDE 内置终端启动 exe 时，若环境里存在 `ELECTRON_RUN_AS_NODE=1`，应用会退化为纯 Node 模式而无法开窗。用资源管理器双击不受影响。
